# Handwritten Formula Solver

This project is a web-based application that recognizes handwritten mathematical equations and solves them automatically.

## Features
- Image upload / camera / text input
- OCR using EasyOCR
- Equation solving using SymPy
- Step-by-step solution
- PDF report generation

## Technologies Used
- Python
- Streamlit
- EasyOCR
- OpenCV
- SymPy
- SQLite

## How to Run
1. Install requirements:
   pip install -r requirements.txt

2. Run the app:
   streamlit run app.py
